# Latest verified Enterprise Safe Contracts APK

This folder belongs only to the `enterprise-safecontracts` product line.

Stable retained filename: `EnterpriseSafeContracts-latest.apk`.

A production-verified APK must have a matching `.sha256` sidecar and `VERIFIED.json` provenance generated by `scripts/enterprise_verified_artifacts.py`. Publication additionally requires verified ESC package identity, separate Firebase Android identity, production signing, HTTPS API configuration, real-device evidence, business UAT and explicit evidence that Safe Contract and ESC coexist independently on the same device.

Keep at most one current verified APK here; historical ESC releases belong in GitHub Releases. Never place ESC APKs in `Last verified apk/`.
