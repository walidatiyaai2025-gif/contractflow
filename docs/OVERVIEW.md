# SafeContracts

SafeContracts is a WordPress-backed contract receivables, collections and follow-up platform with a role-aware mobile application.

## Baseline

- WordPress Custom Plugin = complete backend and administration system
- Mobile App = API-driven monitoring/light-edit client
- Roles = System Administrator / Manager / Accountant / Viewer
- 13 WordPress screens + 11 Mobile screens
- 11 delivery phases / 284 production tasks
- Live GitHub status table in `docs/PROJECT_STATUS.md`
