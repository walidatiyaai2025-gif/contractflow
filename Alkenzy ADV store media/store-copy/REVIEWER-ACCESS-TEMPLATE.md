# Play Review — App Access Instructions

Alkenzy ADV requires an authorized account.

Before production submission, create a dedicated review account that:
- is not an administrator;
- contains non-sensitive demo/test data only;
- can access the screens represented in the store listing;
- remains valid throughout Google review;
- does not require OTP, VPN, or manual approval unless those steps are explicitly described to Google.

Fill in Play Console > App content > App access:

Username: `[CREATE BEFORE SUBMISSION]`
Password: `[ENTER ONLY IN PLAY CONSOLE — DO NOT COMMIT]`

Additional instructions: Use the supplied reviewer account to sign in. The account contains test business data and is limited to review-safe permissions.

Never commit the reviewer password to Git.
